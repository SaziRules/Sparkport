TASK 4 — WooCommerce → Supabase Sync (2–3 hrs)
================================================================
Foundation for manager analytics. Do in order.

4a. lib/supabase/wc-sync.ts
  Uses adminClient (service role).

  upsertOrder(wcOrder):
    - Upsert wc_orders (onConflict: 'id')
    - Delete wc_order_items for this order_id, re-insert all line_items
    - If customer_id > 0: upsertCustomer from order billing data

  upsertCustomer(wcCustomer):
    - Upsert wc_customers (onConflict: 'wc_id')

  awardOrderPoints(order):
    - Look up Supabase user by email (adminClient.auth.admin.listUsers())
    - If no user: skip (guest order)
    - Check no existing rewards_transaction for reference = order.id.toString()
    - Points = Math.floor(parseFloat(order.total))
    - Insert rewards_transaction (type: 'order_completed')
    - Upsert rewards (increment points, recalculate tier)

4b. app/api/webhooks/woocommerce/route.ts
  POST handler:
    - Read raw body as text
    - HMAC-SHA256 validate against WC_WEBHOOK_SECRET (401 if mismatch)
    - Get topic from X-WC-Webhook-Topic header
    - Route: order.created / order.updated → upsertOrder → awardOrderPoints if completed
    - Route: customer.created / customer.updated → upsertCustomer
    - Always return 200 immediately

  Add to .env.local: WC_WEBHOOK_SECRET=<random 32+ char string>

4c. scripts/wc-backfill.ts
  - Paginate GET /wc/v3/orders?per_page=100&page=N until empty
  - Paginate GET /wc/v3/customers?per_page=100&page=N until empty
  - Call upsertOrder / upsertCustomer for each
  - After: for each completed order missing a rewards_transaction, call awardOrderPoints
  - Log progress per page
  Run: npx ts-node scripts/wc-backfill.ts

4d. WC Admin webhook setup (manual — do after 4b is deployed)
  WC Admin → Settings → Advanced → Webhooks → Add:
    Order created   → https://[domain]/api/webhooks/woocommerce
    Order updated   → same
    Customer created → same
    Customer updated → same
  Secret: same value as WC_WEBHOOK_SECRET
  API version: WP REST API Integration v3
  Click Test on each, verify 200.
