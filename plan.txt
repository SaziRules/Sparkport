2.1  Create lib/wordpress/config.ts (NEW FILE)
     - Export WP_API constant = process.env.NEXT_PUBLIC_WP_API_URL
     - Export WC_API constant = WP_API + '/wc/v3'

         Removes HTML tags for excerpt plain-text conversion

         REVALIDATE_POSTS = 3600      (1 hour)
         REVALIDATE_PRODUCTS = 300    (5 minutes)
         REVALIDATE_CATEGORIES = 86400 (24 hours)

2.2  Create lib/wordpress/posts.ts (NEW FILE)
     Implement these functions (all server-side, all using Next.js fetch()):

     getPosts(params?: {
       per_page?: number   default: 12
       page?: number       default: 1
       category?: number   WP category ID
       search?: string
     }) → Promise<BlogPost[]>
       Endpoint: GET /wp/v2/posts?_embed&per_page=N&page=N
       Mapping:
         post.title.rendered            → title (run through stripHtml)
         post.excerpt.rendered          → excerpt (stripHtml, trim)
         post.content.rendered          → content (raw HTML, kept for rendering)
         post.slug                      → slug
         post.date                      → date
         post._embedded['wp:featuredmedia'][0].source_url → image
         post._embedded['wp:featuredmedia'][0].alt_text  → imageAlt
         post._embedded['wp:term'][0].map(t => t.name)   → categories
         post._embedded.author[0].name  → author.name
         post._embedded.author[0].avatar_urls['96'] → author.avatar
         post.yoast_head_json.title     → seo.title
         post.yoast_head_json.description → seo.description
         post.yoast_head_json.og_image?.[0]?.url → seo.ogImage
       Cache: { next: { revalidate: REVALIDATE_POSTS } }

     getPostBySlug(slug: string) → Promise<BlogPost | null>
       Endpoint: GET /wp/v2/posts?slug={slug}&_embed
       Returns mapped BlogPost or null if empty array

     getAllPostSlugs() → Promise<string[]>
       Endpoint: GET /wp/v2/posts?per_page=100&_fields=slug
       Used for generateStaticParams() in blog/[slug]

     getBlogCategories() → Promise<Category[]>
       Endpoint: GET /wp/v2/categories?per_page=100&hide_empty=true
       Returns only categories with count > 0

2.3  Create lib/wordpress/products.ts (NEW FILE)
     All functions use wcAuthHeaders() for Authorization header.

     getProducts(params?: {
       per_page?: number   default: 20
       page?: number       default: 1
       category?: number   WC category ID
       on_sale?: boolean
       featured?: boolean
       search?: string
       orderby?: 'date' | 'price' | 'popularity' | 'rating'
       order?: 'asc' | 'desc'
     }) → Promise<Product[]>
       Endpoint: GET /wc/v3/products?status=publish&per_page=N
       Mapping:
         product.id                     → id
         product.name                   → name
         product.slug                   → slug
         product.categories[0]?.name   → category
         product.categories.map(c=>c.name) → categories
         product.tags.map(t=>t.name)   → tags
         parseFloat(product.regular_price) → originalPrice
         parseFloat(product.price)     → salePrice
         product.images[0]?.src        → image
         product.images[0]?.alt        → imageAlt
         product.stock_status === 'instock' → inStock
         product.on_sale               → onSale
         product.featured              → featured
         product.short_description     → shortDescription (keep HTML)
         product.description           → description (keep HTML)
         product.sku                   → sku
       Cache: { next: { revalidate: REVALIDATE_PRODUCTS } }

     getProductById(id: number) → Promise<Product | null>
       Endpoint: GET /wc/v3/products/{id}
       Returns mapped Product or null

     getAllProductIds() → Promise<number[]>
       Endpoint: GET /wc/v3/products?per_page=100&_fields=id&status=publish
       Used for generateStaticParams() in product/[id]

     getProductCategories() → Promise<Category[]>
       Endpoint: GET /wc/v3/products/categories?per_page=100&hide_empty=true
       Maps: id, name, slug, count, image?.src
       Cache: { next: { revalidate: REVALIDATE_CATEGORIES } }

     getFeaturedProducts(limit?: number) → Promise<Product[]>
       Calls getProducts({ featured: true, per_page: limit ?? 4 })

     getOnSaleProducts(limit?: number) → Promise<Product[]>
       Calls getProducts({ on_sale: true, per_page: limit ?? 20 })

     getProductsByCategory(categorySlug: string, limit?: number) → Promise<Product[]>
       First: find category ID from getProductCategories() by slug
       Then: getProducts({ category: id, per_page: limit ?? 20 })

     getNewArrivals(limit?: number) → Promise<Product[]>
       Calls getProducts({ orderby: 'date', order: 'desc', per_page: limit ?? 4 })

2.4  Create lib/wordpress/index.ts (NEW FILE)
     Re-export everything from posts.ts and products.ts
     Single import point for all API calls:
       import { getProducts, getPosts, getPostBySlug, ... } from '@/lib/wordpress'

PHASE 7 — CART INTEGRATION
================================================================

7.1  Research the right cart approach
     WooCommerce exposes two APIs for cart:
       A) WooCommerce Store API (wc/store/v1) — public, uses nonce + session cookie,
          no consumer keys needed, built for headless frontends. RECOMMENDED.
       B) WooCommerce REST API cart — requires per-customer auth, complex.
     Use option A: WooCommerce Store API

7.2  Create lib/wordpress/cart.ts (NEW FILE)
     Implement cart functions using /wc/store/v1:
       getNonce() → fetch nonce from /wc/store/v1
       getCart() → GET /wc/store/v1/cart
         Returns: { items: CartItem[], totals: CartTotals, items_count: number }
       addToCart(productId: number, quantity: number) → POST /wc/store/v1/cart/add-item
       updateCartItem(key: string, quantity: number) → PUT /wc/store/v1/cart/items/{key}
       removeCartItem(key: string) → DELETE /wc/store/v1/cart/items/{key}
       clearCart() → DELETE /wc/store/v1/cart/items
     Define CartItem type: { key, id, quantity, name, price, totals, images }
     All requests include 'Nonce' header and handle session cookies

7.3  Update contexts/CartContext.tsx
     - Replace TODO comment with real implementation
     - State: items: CartItem[], itemCount: number, isLoading: boolean
     - On mount: getCart() to hydrate state
     - addToCart(productId, quantity): call cart API, update state
     - removeFromCart(key): call cart API, update state
     - updateQuantity(key, quantity): call cart API, update state
     - Persist cart via WooCommerce session cookie (handled automatically)
